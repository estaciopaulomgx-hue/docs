# DocTrack

Pre-configured with Lovable Cloud. **No setup needed.**

## Run
Open `index.html` in your browser (or use VS Code Live Server).

The database table `uploads` and storage bucket `documents` are already
provisioned in Lovable Cloud. Uploads, downloads, deletions, and real-time
updates work out of the box.

## Files
- `index.html`, `style.css`, `script.js` — your original app, unchanged
- `supabase-config.js` — pre-filled Lovable Cloud credentials
- `supabase-setup.sql` — reference SQL (already executed in the cloud)
